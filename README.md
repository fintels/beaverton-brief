# Beaverton Daily Brief: content

Automated, source-cited daily briefs for Beaverton and Washington County, Oregon. This is a proof of concept.

- `briefs/YYYY-MM-DD.html`: one brief per day. Every item links to its source, and each brief ends with a note on how it was made.
- `index.json`: the list of available briefs, newest first.

The briefs are generated from public sources (local news RSS feeds, FlashAlert, city and county meeting portals, Oregon open data and NWS) and drafted by Claude.
